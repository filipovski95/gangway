# App icon

Since 25 Oct 2026 the app icon is the ship-at-the-gangway artwork in `brand/icon-art-master.png` (a square crop of the Canva crew-flyer illustration, with the "SORTED." lettering removed and the dark corner filled with navy #0F2A3A).

Everything in `brand/res/` (launcher icons, round icons, adaptive foregrounds, splash screens), `brand/play-icon-512.png`, `store/play-icon-512.png` and the icon on `store/feature-graphic-1024x500.png` was made from that file.

The SVG files and `gen.py` / `build.js` in this folder produce the **old** drawn icon. Don't run them unless you want the old icon back.
